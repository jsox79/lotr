## Preservation Rule

Omission is not deletion. Previously named characters, rules, cards, factions, regions, Allies, Enemies, Artifacts, Locations, Titles, Boons, and mechanics remain preserved until explicitly removed.

## Current Architecture

Shadow & Fellowship is a fully digital tabletop game:

- TV/shared display = living Master Map / Table View.
- Phone/tablet = private Player Console.
- Authoritative server = rules, decks, RNG, hidden state, movement, combat, corruption, and victory.

The old physical-card + companion-PWA architecture is retired.

## Current Core Design

**Stacking builds power. Regional control wins games. Movement creates risk. Corruption creates temptation. Combat changes ownership.**

Regional Movement Decks are separate from the Universal Deck and trigger only when crossing into/through their region.

Player movement does not automatically cause battle.

Gollum remains random Ring disruption, not a player-controlled resource.
